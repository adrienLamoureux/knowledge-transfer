  • Learn a cloud by mapping what you run, then the few concepts that differ.

  • Price code by multiplying loops. Most problems match a dozen patterns.
  • Names and dates move. Re-check before quoting.

K3 Standing-cost traps and zero-idle design

P3 referenceLesson

Every component should cost about nothing when nobody uses it.

Bills while idleAt small scale, use
A dedicated vector-search serviceThe database's vector index
A global load balancer plus CDNManaged hosting with rewrites
Managed SQL for session stateA serverless document store
Managed Redis for a shared cacheA per-instance cache, short TTL
Self-hosted GPUsPer-second GPU billing
NAT, provisioned concurrencyNo private egress, on-demand

Quote prices as dated, order-of-magnitude anchors, never as quotes.

L3 Algorithm patterns and their triggers

P3 referenceNotes

Thirty seconds of triage picks the pattern.

  1. What is returned? One number or all answers: DP or backtracking.
  2. Is it sorted? Two pointers, binary search.
  3. How big is n? 10^5 to 10^6 allows O(n log n).
