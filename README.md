# Knowledge transfer

General engineering principles: architecture, APIs, frontend, data, operations, security, AI and
the forward-deployed (FDE) approach. Open `index.html` to read; `INDEX.md` lists every doc.

Each doc is an Archon twin: `<slug>.html` for people, `<slug>.md` for coding agents (the MD is
canonical). Built and linted with the `docs-kit` plugin from `claude-skills`.

Sources are labelled Practice (public links), Notes (private study notes, no ref), Lesson
(learned on real systems, unnamed) and Case (one hypothetical worked case).
